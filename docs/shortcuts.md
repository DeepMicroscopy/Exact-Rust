# Keyboard shortcuts
The shortcuts of the old EXACT interface were kept. Shortcuts are ignored while you type in a text field.

| Key | Action |
|---|---|
| `1` – `9` | choose the annotation type to draw; with an annotation selected, change its class |
| `Shift` + `1` – `9` | set an image-level (global) label |
| `C` | switch between selecting and drawing |
| `A` | one-click mode: every click places an annotation of the type's default size |
| `Enter`, `V` | finish the annotation being drawn |
| `Esc` | cancel drawing or editing, clear the selection |
| `Delete`, `Backspace`, `X` | delete the selection |
| `Y` | show or hide annotations |
| `S` | scissors: cut an area away from the selected polygon |
| `G` | glue: add an area to the selected polygon |
| `D` | knife: split the selected polygon along a line |
| `Shift` + drag / `Alt` + drag | brush: add area / erase area of a selected polygon |
| `Ctrl` / `⌘` + `Z` | undo |
| `Ctrl` / `⌘` + `Shift` + `Z`, `Ctrl` + `Y` | redo |
| `Ctrl` / `⌘` + `A`, `C`, `V` | select all, copy, paste annotations |
| `E`, `Q` | next, previous image of the image set |
| `Shift` + `E`, `Shift` + `Q` | next, previous frame |
| `Page Up`, `Page Down` | next, previous frame (slice in the three-plane view) |
| `Space` | play or pause a movie |
| arrow keys | pan |
| `Shift` + `↑` / `↓`, `+` / `-` | zoom |
| `0` | fit the image to the window |

Dropped on purpose: the heat map key, `R` (finish; it clashed with rotate) and `F` (verify image; verification is not part of
the new interface).
